**Automated Student Data Import, Intelligent Seating Allocation & AI-Driven QA**

Built for the **Tactive AI-Powered QA Automation, Documentation & Software Engineering Assessment**.

---

## 📌 Project Overview

The **AI-Assisted Exam Hall & Seat Allocation System** is a Flask-based web application designed to automate and simplify examination seating management.

The system allows an examination administrator to take raw student examination data from **Excel, CSV, or PDF files**, validate the records, group students into examination sessions, configure multiple examination halls, automatically allocate seats, view seating plans, search for individual students, and export the final seating information.

The project also demonstrates an **AI-assisted software development and QA workflow**, where AI tools were used for implementation, testing, debugging, documentation, and analysis, while the final implementation was verified through actual application execution and automated testing.

---

# 🎯 Problem

A college examination administrator needs to take a raw student examination list and convert it into a valid hall-and-seat allocation.

When this process is performed manually, several problems can occur:

- Duplicate student allocations
- Double-booked seats
- Hall capacity being exceeded
- Invalid or incomplete student records
- Incorrect examination dates or times
- Duplicate register numbers
- Difficulty managing multiple examination halls
- Difficulty finding an individual student's seat
- Difficulty handling large student datasets
- Lack of clear records for students who could not be seated

The system addresses these problems by providing an automated and centralized examination seating management workflow.

# 📅 Examination Session Management

Students are automatically grouped into examination sessions using:

```text
Subject + Exam Date + Exam Time
```

Each session can be managed independently.

---

# 🏫 Examination Hall Management

The system supports multiple examination halls.

Each hall can be configured using:

- Hall name
- Number of rows
- Number of columns
- Seating capacity
- Active / inactive status

Capacity is calculated as:

```text
Capacity = Rows × Columns
```

Example:

```text
5 rows × 4 columns = 20 seats
```

Multiple halls can be used when one hall does not have sufficient capacity.

---

# 💺 Intelligent Seat Allocation

The allocation engine automatically assigns students to available examination halls and seats.

It prevents invalid allocations and reports students who cannot be allocated when capacity is insufficient.

Example:

```text
Students: 40

Hall 1: 20 seats
Hall 2: 20 seats

Total Capacity: 40

Allocated: 40
Unallocated: 0
```

# 📐 Allocation Business Rules

1. Every allocated student receives exactly one seat.
2. A single seat cannot be assigned to more than one student.
3. Hall capacity cannot be exceeded.
4. A student cannot be allocated twice for the same examination session.
5. Duplicate register numbers are rejected during import.
6. Only students in the selected session are allocated.
7. Students who cannot be seated because of insufficient capacity are reported.
8. A student cannot be double-booked at the exact same date and time across different sessions.
