# Sample Data

All fictional. Regenerate anytime with `python scripts/generate_sample_data.py`.

| File | Purpose |
|---|---|
| `students.xlsx` / `students.csv` | 40 valid records, demo dataset — pair with 2 halls of 20 seats to see allocation span both halls |
| `students.pdf` | 15 valid records in a readable table, for testing PDF import |
| `invalid_students.xlsx` | One row per validation rule: missing register number, missing name, missing subject, invalid date, invalid time, duplicate register number |
